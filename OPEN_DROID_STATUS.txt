7. AGENT CORE
Pipeline Sequence Implemented:
1. User prompt received by AgentCore.executeTask().
2. Initial TaskEntity inserted into Room with status CREATED.
3. Task status transitioned to ANALYZING.
4. AgentCore formats prompt and enforces production GBNF grammar (TOOL_DECISION_GBNF).
5. Dispatches request over Binder IPC (InferenceClient) to InferenceService running in :inference process.
6. Native llama.cpp runs constrained autoregressive decode loop, streaming tokens back via IInferenceCallback.
7. AgentCore parses validated JSON into StructuredModelDecision (ToolCall or DirectResponse).
8. If ToolCall:
   a. Checks tool existence in ToolRegistry.
   b. Performs parameter schema validation.
   c. Evaluates deterministic RiskEngine tier (SAFE / CONFIRM / HIGH_RISK / BLOCKED).
   d. If BLOCKED: Marks task FAILED in Room and aborts.
   e. Generates RFC 4122 UUIDv5 idempotency key.
   f. Inserts TaskStepEntity in Room via atomic recordStepIfNew transaction. If duplicate, skips execution.
   g. If CONFIRM or HIGH_RISK: Transitions task to WAITING_CONFIRMATION and pauses for user approval.
   h. Transitions task to EXECUTING and executes real AndroidTool API.
   i. Transitions task to VERIFYING and runs post-execution verification check.
   j. Updates step and task in Room with status COMPLETED and records execution result.

8. RISK ENGINE
Deterministic Risk Tiers:
- SAFE: Executes immediately without prompting (e.g., query battery info, read status).
- CONFIRM: Requires explicit user dialog approval before execution (e.g., toggle flashlight, change media volume).
- HIGH_RISK: Requires user confirmation and displays high-risk security warning (e.g., launch third-party app, system state mutation).
- BLOCKED: Automatically rejected by Risk Engine; execution is forbidden (e.g., unauthorized packages, illegal commands).

11. EMERGENCY STOP
Cancellation Propagation:
1. EmergencyStopManager.triggerEmergencyStop(reason) sets atomic boolean isActive = true.
2. AgentCore checks isEmergencyStopActive() at every pipeline step (pre-inference, pre-validation, pre-execution, post-execution).
3. If active, AgentCore dispatches cancelInflightInference() to InferenceClient.
4. InferenceClient calls IInferenceService.cancelInference() across Binder IPC to :inference process.
5. InferenceService calls NativeLlamaCppAdapter.cancelCurrentExecution().
6. JNI function cancelExecutionNative() sets C++ std::atomic<bool> g_cancel_requested = true.
7. llama_decode token loop detects cancellation flag and breaks immediately.
8. AgentCore catches CancellationException, updates Room TaskEntity status to FAILED/CANCELLED with error message, and halts tool execution.
